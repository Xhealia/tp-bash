# Librairie

Application web de vente de livres en ligne.

- `app/front` : interface des clients
- `app/api` : API qui gère le catalogue, le panier et les commandes
- `logs` : journal des requêtes reçues par l'API
- `tmp` et `cache` : fichiers temporaires, qui peuvent être supprimés sans risque

Avant le premier lancement, on copie `.env.example` en `.env` et on renseigne les valeurs.
